FastMarket

## Descripción

FastMarket es una plataforma e-commerce enfocada en:

- Gestión de inventario
- Procesamiento de pedidos
- Logística y envíos
- Notificaciones
- Reportes

La solución utiliza una arquitectura basada en microservicios para mejorar:

- Escalabilidad
- Rendimiento
- Tolerancia a fallos
- Mantenimiento

## Tecnologías

### Frontend
- Angular
- TypeScript
- Angular Material
- RxJS

### Backend
- Node.js
- Express.js
- PostgreSQL
- MongoDB
- RabbitMQ

### DevOps
- Docker
- Kubernetes
- GitFlow

## Arquitectura

Microservicios principales:

- API Gateway
- Auth Service
- Inventory Service
- Order Service
- Logistics Service
- Notification Service
- Report Service
